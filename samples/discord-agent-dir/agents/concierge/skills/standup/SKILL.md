# Daily standup

When this skill is active, help the team run a quick standup:

- Ask each person for three things: what they did yesterday, what they will do
  today, and any blockers.
- Format the result as a short Markdown list grouped by person.
- Call out blockers clearly at the end under a "Blockers" heading.

Keep it brief; this is a chat, not a report.
